Release Please maintains the canonical
[CHANGELOG.md](https://github.com/jbcom/jeep-sqlite-current-sqljs/blob/main/CHANGELOG.md), version metadata,
tags and GitHub Releases. Published releases use npm provenance.

Versions continue upstream's line: `2.9.0` is the first release of this package, built from
upstream `2.8.0` (see [Decisions](decisions.md) for why a minor and not a prerelease). The same
changelog also keeps
[jepiqueau/jeep-sqlite](https://github.com/jepiqueau/jeep-sqlite)'s release notes from 1.5.0
through 2.8.0, which are the history of the component itself.

For planned changes, use a Conventional Commit type such as `fix:`, `feat:`, `docs:`,
`refactor:`, `test:` or `chore:`. Breaking public API changes need a `!` or `BREAKING CHANGE:`
footer.
